# StudyGrow

Python と Flet で作った、ブラウザで使える学習サポートアプリです。ホーム画面ではランダムな応援コメントを表示でき、「学習計画」「課題」「カレンダー」を選べます。学習計画ではタスクの追加、完了切替、削除、状態別の絞り込みができます。「課題」では自分の課題を追加し、一覧から完了状況の切替や削除ができます。課題は学習計画のタスクとは別にユーザーのホームディレクトリに保存されます。カレンダーでは月の移動と日付の選択に加えて、選択した日の予定を追加・削除できます。選択した日の予定はカレンダー横の大きな吹き出しに箇条書きで表示され、予定はユーザーのホームディレクトリに保存されます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

Codespaces で起動した場合は、ポート `8000` を公開し、表示された転送 URL をブラウザで開いてください。

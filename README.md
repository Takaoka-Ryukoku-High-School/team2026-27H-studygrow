# StudyGrow

Python と Flet で作った、ブラウザで使える学習サポートアプリです。ホーム画面ではランダムな応援コメントを表示でき、「学習計画」「課題」「カレンダー」「ストップウォッチ」を選べます。画面上部の表示モード切替から、日本語・英語・ひらがなモードを変更できます。英語モードとひらがなモードでは、保存済みの利用者データは変換せず、そのまま表示します。学習計画には日付ごとに選ばれるランダム課題が1つ表示され、「計画に追加」から今日のタスクへ追加できます。学習計画ではそのほか、タスクの追加、完了切替、削除、状態別の絞り込みができます。「課題」では自分の課題を追加し、一覧から完了状況の切替や削除ができます。課題は学習計画のタスクとは別にユーザーのホームディレクトリに保存されます。カレンダーでは月の移動と日付の選択に加えて、選択した日の予定を追加・削除できます。選択した日の予定はカレンダー横の大きな吹き出しに箇条書きで表示され、予定はユーザーのホームディレクトリに保存されます。ストップウォッチは開始・一時停止・再開・ラップ・リセットができ、計測中はほかの画面操作がロックされます。ラップを記録すると区間時間と合計経過時間を一覧表示し、リセットすると一覧もクリアされます。ストップウォッチ画面にはタイマーもあり、時間・分・秒を選択して設定できます（時間0〜24、分・秒0〜60）。計測中に操作できるのは一時停止とラップだけです。終了時にはプログラムで生成した短いアラームが鳴り、計測中は外部音源を使わない環境音が再生されます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

Codespaces で起動した場合は、ポート `8000` を公開し、表示された転送 URL をブラウザで開いてください。

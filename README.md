# StudyGrow

Python と Flet で作った、ブラウザで使える学習サポートアプリです。ホーム画面ではランダムな応援コメントを表示でき、「学習計画」「課題」「カレンダー」を選べます。学習計画ではタスクの追加、完了切替、削除、状態別の絞り込みに加えて、英単語を辞書で検索して登録し、カード形式で学習できます。単語と習得状況はユーザーのホームディレクトリに保存されます。「課題」では自分の課題を追加し、一覧から完了状況の切替や削除ができます。課題は学習計画のタスクとは別にユーザーのホームディレクトリに保存されます。カレンダーでは月の移動と日付の選択に加えて、選択した日の予定を追加・削除できます。選択した日の予定はカレンダー横の大きな吹き出しに箇条書きで表示され、予定はユーザーのホームディレクトリに保存されます。

英単語画面では [Free Dictionary API](https://dictionaryapi.dev/) を使って英単語の英語定義を検索し、確認後に辞書へ登録できます。発音は検索結果に表示し、例文が返された場合は登録してカードでも確認できます。このAPIは日本語訳を提供しないため、日本語への翻訳機能ではありません。検索結果にはアプリ内でも出典を表示しています。

このアプリはAPIのソフトウェアを同梱せず、APIにリクエストして辞書データを利用します。APIプロジェクトのソースコードは [GPL-3.0](https://github.com/meetDeveloper/freeDictionaryAPI/blob/master/LICENSE) で公開されていますが、これはAPIレスポンス内の辞書データのライセンスを明示するものではありません。辞書データの利用・再配布条件は提供元の最新情報を確認してください。StudyGrowは出典としてFree Dictionary APIを表示し、登録したデータはユーザーのホームディレクトリに保存します。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

Codespaces で起動した場合は、ポート `8000` を公開し、表示された転送 URL をブラウザで開いてください。

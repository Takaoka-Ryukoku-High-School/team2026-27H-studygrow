# StudyGrow

Python と Flet で作った、ブラウザで使える学習サポートアプリです。ホーム画面から「学習計画」「課題の確認」「カレンダー」を選べます。学習計画ではタスクの追加、完了切替、削除、状態別の絞り込みに加えて、英単語と日本語の意味を登録し、カード形式で学習できます。単語と習得状況はユーザーのホームディレクトリに保存されます。課題の確認では未完了のタスクを表示します。カレンダーでは月の移動と日付の選択に加えて、選択した日の予定を追加・削除できます。予定はカレンダーの日付ごとに表示され、ユーザーのホームディレクトリに保存されます。

英単語画面では英単語と日本語の意味を手入力して登録し、カード形式で学習できます。例文と例文訳も必要に応じて手入力できます。外部辞書を使った自動翻訳・検索機能はありません。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

Codespaces で起動した場合は、ポート `8000` を公開し、表示された転送 URL をブラウザで開いてください。
